# Оптимальное управление посадкой БПЛА (принцип максимума Понтрягина)

Численное построение оптимальной по быстродействию посадочной траектории БПЛА (тип «Орлан-10») с
учётом динамических ограничений на управление. Оптимальные управления получены аналитически из
**принципа максимума Понтрягина**, а соответствующая нелинейная **краевая задача решается методом
продолжения по параметру** (метод «малых деформаций» Аввакумова–Киселёва).

> **Short summary (EN).** Time-optimal landing trajectory of a fixed-wing UAV via Pontryagin's maximum
> principle. The optimal load-factor and roll controls are of relay type and are smoothed by a
> parameter ν for differentiability; the resulting two-body boundary-value problem (state + costate) is
> solved by single shooting embedded in a **parameter-continuation homotopy**: the shooting residual is
> deformed from its initial value to zero along μ ∈ [0, 1]. Correctness of the maximum-principle
> implementation is verified numerically (see `src/verify.py`).

## Постановка

Движение БПЛА в траекторной системе координат описывается системой (фазовый вектор
`x = [v, θ, ψ, h, l, z]`, управление `u = [nX, nY, nZ, γ]` — продольная, нормальная, боковая
перегрузки и угол крена):

```
v̇ = g (nX − sin θ)
θ̇ = g (nY cos γ − nZ sin γ − cos θ) / v
ψ̇ = −g (nY sin γ − nZ cos γ) / (v cos θ)
ḣ = v sin θ,   l̇ = v cos θ cos ψ,   ż = −v cos θ sin ψ
```

Требуется за время `t*` перевести аппарат из начального состояния в целевую точку захода на посадку
при ограничениях `nX, nY, nZ, γ ∈ [·min, ·max]`. Критерий качества — функционал с функцией Ляпунова
`V(v, h)` (изменение кинетической и потенциальной энергии). Полная постановка, вывод гамильтониана,
сопряжённой системы и доказательства релейности управлений — в
[`docs/Постановка_и_аналитическое_решение.pdf`](docs/Постановка_и_аналитическое_решение.pdf).

## Метод

1. **Оптимальные управления.** Из максимума гамильтониана управления получаются релейными
   (`sign`/`sat` от переключающих функций). Для дифференцируемости краевой задачи они сглаживаются
   параметром `ν`:  `SGN(s,ν)=s/√(ν+s²)`,  `SAT(s,ν)=½(√(ν+(s+1)²)−√(ν+(s−1)²))`.
2. **Краевая задача.** Ищется начальный сопряжённый вектор `p₀`, при котором траектория расширенной
   системы `[x, p]` приходит в целевую точку: `Φ(p₀) = x(t*; p₀) − x_f = 0` (одиночная пристрелка).
3. **Продолжение по параметру.** Невязка обнуляется постепенно: `Φ(p₀(μ)) = (1−μ)·Φ(p₀_start)`,
   `μ: 0 → 1`, на каждом шаге — демпфированный метод Ньютона. Идея из статьи
   [Аввакумов, Киселёв, 2006](docs/Аввакумов_Киселёв_2006_алгоритмы_оптимального_управления.pdf).

## Проверка корректности

`python src/verify.py` в 300 случайных точках фазового пространства проверяет, что:

- аналитическая сопряжённая система совпадает с численной `−∂H/∂x` (расхождение ~10⁻⁶);
- найденные управления действительно доставляют максимум гамильтониану (ни одно допустимое
  управление не даёт большего `H`).

Оба теста проходят — реализация принципа максимума корректна.

## Замечание о сходимости

Краевая задача решается одиночной пристрелкой. Отображение `p₀ → x(t*)` для нелинейной системы на
конечном горизонте обладает высокой чувствительностью (число обусловленности растёт с длиной
интервала), поэтому из произвольного начального приближения продолжение может сходиться к неоптимальному
локальному минимуму. Для устойчивой сходимости на длинных горизонтах естественное развитие — переход к
**множественной пристрелке (multiple shooting)** либо коллокации, что вынесено в дальнейшую работу.
